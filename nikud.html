How to calibrate this master reading
  1. Read every word correctly for Reading A.
  2. First compare another correct reading to check ordinary voice variation.
  3. Next record Reading B again with one or more deliberate vowel mistakes.
  4. Mark all Reading B vowels correct, then mark only the deliberate mistakes wrong.
  5. Check the number of catches, false alarms, and misses.
