How to judge: does the transcript match the letters of what you read (ignore vowels/nikud — the model doesn't output those, and that's fine)? If it's close, a real model is the answer and I'll build it into the trainer. If it's still off, we'll know browser-only won't cut it.

Notes / honest caveats:
  • First load downloads the model (cached afterward on this device). On a slow connection or a Chromebook, tiny/base load faster; small is more accurate but heavier.
  • This runs on WebGPU if your browser supports it (fast), otherwise falls back to CPU (slower). The device in use is shown above.
  • Transcription happens after you finish reading (a few seconds), not live word-by-word. For an accurate graded test that's the right trade.
  • These are general multilingual Whisper models. If Hebrew accuracy is close but not perfect, there are Hebrew-specialized models (ivrit.ai) we can try next.
